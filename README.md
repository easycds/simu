# Version publique

Ce dépôt contient la version publiée sur easycds.fr : le site vitrine et les pages publiques en clair, les espaces moniteurs et direction **chiffrés**.
Le code source lisible est dans le dépôt privé `easycds/easy-sources` : toute modification se fait là-bas, puis `node outils/chiffrer.mjs` régénère ce dépôt.
